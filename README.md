# SamTracker

An offline, Mactracker-inspired reference tool built for Android, providing exhaustive technical specifications, hardware metrics, and historical backgrounds for Samsung devices. *Fully vibe-coded with small human corrections.*

## Features

* **Exhaustive Hardware Database:** Detailed specs spanning smartphones, tablets, wearables, and audio gear.
* **Material You UI:** Built with Jetpack Compose, featuring a sliding drawer and dark mode support.
* **100% Offline:** No cloud dependency or tracking.

## Tech Stack

* **Language:** Kotlin
* **UI Framework:** Jetpack Compose (Material 3)
* **Architecture:** MVVM / Repository pattern
